# سناریوی دموی لیاراپایلوت (حدود ۵ دقیقه — مطابق الزام چالش)

> سه صندلی پشتیبان برای پایداری دمو:
> ۱) **استقرار واقعی** روی حساب لیارا (بهترین حالت — نیازمند اعتبار فعال روی حساب)،
> ۲) **URL از پیش استقرار یافته** اگر شبکه کند بود،
> ۳) **حالت آفلاین کامل** با `DEMO_MODE=1` (FakeLLM + MockDeployer) — بدون هیچ تماس بیرونی.
>
> صحنه‌ها طوری چیده شده‌اند که اگر اعتبار نبود، فقط صحنه‌های «استقرار واقعی» با موک جایگزین شوند
> و بقیه دمو دست‌نخورده بماند.

## آماده‌سازی (پیش از شروع تایمر)

```bash
# حالت واقعی (بهترین دمو): کلید BoxAPI در .env + توکن لیارا در env
cp .env.example .env            # LLM_API_KEY را پر کن (LLM واقعی، نه Fake)
export LIARA_API_TOKEN=<توکن پنل لیارا>   # فقط در RAM — هرگز در صفحه/لاگ/گیت
export DEPLOYER=liara_api DEMO_MODE=0 RATE_LIMIT_PER_MIN=60 RATE_LIMIT_GLOBAL_M=600
python -m uvicorn app.main:app --host 0.0.0.0 --port 3000
```

- یکبار قبل از ضبط: `python3 scripts/live_check.py` را اجرا کن تا خروجی PASS تازه داشته باشی.
- پلن تست: `ir-small` (کوچک‌ترین — با 400 API خود لیارا فهرست شده). بعد از دمو، اپ تست را از پنل **حذف کن**.
- تب دوم مرورگر: `docs/VERIFIED_MATRIX.md` در گیت‌هاب. تب سوم: پنل لیارا (برای لحظه‌ی حذف اپ تست).

## صحنه ۱ — مشکل و معرفی (۰:۰۰ تا ۰:۳۰)

**روی صفحه:** صفحه‌ی فرود تمیز LiaraPilot (تم تیره، بج «چالش لیارا»).

**متن گوینده:**
«هر برنامه‌نویسی پروژه‌اش را تمام می‌کند، ولی استقرار یک دیوار است: پورت، دیسک ماندگار، متغیر محیطی، لاگ…
لیاراپایلوت یک ایجنت است که کل این مسیر را انجام می‌دهد: پروژه را می‌گیرد، سطح تجربه‌ات را می‌سنجد،
ریسک‌ها را قطعی بازرسی می‌کند، قبل از هر کار هزینه‌دار از تو اجازه می‌گیرد، با API رسمی لیارا مستقر می‌کند،
لاگ واقعی می‌خواند و اگر خراب شد تا سه بار خودش را اصلاح می‌کند. ببینیم.»

## صحنه ۲ — اعتبار فنی: چسبیده‌ایم به API واقعی (۰:۳۰ تا ۱:۰۰)

**اقدام:** ترمینال را نشان بده؛ `live_check.py` را اجرا کن (خروجی PASS مرحله‌به‌مرحله).
سریع به `VERIFIED_MATRIX.md` سوئیچ کن و چند سطر PASS/FAIL واقعی را نشان بده.

**متن گوینده:**
«قبل از هرچیز، بگذار ثابت کنم این ایجنت با API واقعی لیارا حرف می‌زند، نه با موک.
این اسکریپت صحت‌سنجی، مرحله‌به‌مرحله با توکن واقعی API را صدا می‌زند و هر مرحله PASS یا FAIL می‌شود.
هر فکتی که محصول ادعا می‌کند یا فراخوانی واقعی پشتش است، یا سند رسمی OpenAPI —
چیزی که مستند نباشد، صادقانه UNVERIFIED برچسب می‌خورد. حتی جواب خطای API را برای فهمیدن
شناسه‌ی پلن‌های معتبر استفاده کردیم.»

## صحنه ۳ — آپلود، سنجش، ریسک‌ها (۱:۰۰ تا ۱:۵۰)

**اقدام:** چیپ «فروشگاه عطر» (Next.js + Prisma + SQLite) → ۴ سؤال با گزینه‌های مبتدیانه → «شروع».
روی استپر گرافیکی و کارت‌های ریسک زوم کن.

**متن گوینده:**
«چهار سؤال کوتاه تا بفهمد با چه کسی حرف می‌زند. حالا مبتدی است، پس مفهوم‌ها را با تشبیه توضیح می‌دهد.
ببین: تشخیص داد این پروژه SQLite دارد — روی لیارا دیتابیس باید روی دیسک ماندگار باشد، مثل کمدی‌ای
که مبل‌هایت در آن می‌ماند وقتی خانه عوض می‌کنی. رمز پیش‌فرض هم در کد مانده — ریسک امنیتی.
دقت کن: این بازرسی هوش مصنوعی نیست؛ قوانین قطعی است. هوش مصنوعی فقط جاهایی وارد می‌شود
که واقعاً نیاز است.»

## صحنه ۴ — گیت تأیید انسانی (۱:۵۰ تا ۲:۲۰)

**اقدام:** مودال تأیید را تمام‌صفحه نشان بده؛ یکی از مقادیر env را پر کن؛ تأیید کن.

**متن گوینده:**
«مهم‌ترین تصمیم امنیتی محصول: عملیات در سه سطح است — فقط‌خواندنی خودکار، هزینه‌دار با تأیید تو،
و مخرب که اصلاً در دسترس ایجنت نیست. این مودال می‌گوید دقیقاً چه چیزی تغییر می‌کند و هزینه‌اش چیست.
ایجنت ما بدون کلیک تو هیچ چیزی روی لیارا تغییر نمی‌دهد — و نتیجه‌ی هر عملیات با خطای خامِ
رداکت‌شده جلوی چشم توست.»

## صحنه ۵ — استقرار واقعی و کنسول لاگ (۲:۲۰ تا ۳:۱۰)

**اقدام:** دیپلوی را ببین — کنسول ترمینالی لاگ‌های زنده SSE را نشان بده. URL زنده را در تب باز کن.

**متن گوینده:**
«الان ایجنت با API رسمی لیارا اپ را می‌سازد، دیسک را mount می‌کند، سورس را بالا می‌فرستد و بیلد را
دنبال می‌کند — همه‌چیز زنده از لاگ واقعی. دقت کن متن‌ها قبل از نمایش رداکت می‌شوند؛ هیچ رمزی
روی صفحه نیست. و این آدرس زنده است — یک درخواست HTTP واقعی، پاسخ ۲۰۰.»

## صحنه ۶ — خرابی و خود-اصلاح؛ قلب دمو (۳:۱۰ تا ۴:۱۰)

**اقدام:** پروژه‌ی «broken-project» را در جلسه‌ی جدید استقرار بده. شکست → تشخیص → سؤال از کاربر →
پاسخ → استقرار مجدد → موفقیت (یا توقف مسئولانه در تلاش سوم).

**متن گوینده:**
«این مهم‌ترین قسمت است: ایجنت واقعاً ایجنت است، نه اسکریپت. استقرار شکست خورد.
لاگ واقعی را می‌خواند — مدل زبانی تشخیص می‌دهد مشکل چیست، ولی چون مقدار رمز را نباید خودش
بسازد، از من می‌پرسد. پاسخ می‌دهم، اعمال می‌شود، دوباره استقرار. سقف سه تلاش دارد؛ بعدش
مسئولانه می‌ایستد و تصمیم با انسان است. هر رویداد در گزارش ثبت است.»

## صحنه ۷ — پایش و پرسش وسط کار (۴:۱۰ تا ۴:۴۰)

**اقدام:** پنل مانیتور (وضعیت سلامت + تاریخچه) را نشان بده؛ در جعبه پرسش بنویس
«هزینه چقدر می‌شود؟» → پاسخ صادقانه UNVERIFIED؛ بعد «دیسک ماندگار چیست؟».

**متن گوینده:**
«بعد از انتشار، ایجنت سرویس را پایش می‌کند — سلامت و منابع، با تاریخچه‌ی کوتاه و هشدار
وقتی چیزی ناسالم شد؛ پیشنهادش هم از همان ماتریس سه‌سطری می‌گذرد. وسط کار هم می‌توانی
سؤال بپرسی — هر سؤال یک فراخوان مدل، با سقف بودجه.»

## صحنه ۸ — گزارش نهایی و بستن (۴:۴۰ تا ۵:۰۰)

**اقدام:** گزارش پایانی؛ چک‌لیست «چه یاد گرفتی» (مبتدی)؛ اشاره به حالت اکسپرت. پنل لیارا: اپ تست را
**حذف کن** (تصویر حذف = مدیریت هزینه). بستن با یک جمله.

**متن گوینده:**
«برای مبتدی در پایان یک چک‌لیست "چه یاد گرفتی" می‌دهد — هدف فقط دیپلوی نیست، یاد دادن هم هست.
و برای خبره، همان ایجنت خلاصه و بدون توضیح اضافه حرف می‌زند. کارمان که تمام شد، منابع تست را
پاک می‌کنیم — اعتبارتان محترم است. لیاراپایلوت: از "پروژه‌ی تمام‌شده" تا "روی هوا" — با اجازه‌ی تو.»
